# Tin disk diag
A disk diagnostics tool for searching installed disks and to check the disks for any bad sectors. Writen in C.


# building
## requirements
- Time....
- Gnu make
- gcc

## preparing the command
```bash
make # this is just the normal
make static-bin # Compile a static binary. You don't need to run this, this is just because if you want to make a minimal linux distro for disk diagnostics
```
